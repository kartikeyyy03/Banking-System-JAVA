# 🏦 Console Banking System (Java)

A clean, modular console-based banking application built using **Core Java**, demonstrating OOP principles, layered architecture, exception handling, and Java Streams.

---

## 🚀 Features

* ✅ Open bank account
* ✅ Deposit money
* ✅ Withdraw money
* ✅ Transfer funds between accounts
* ✅ View account statement (latest first)
* ✅ List all accounts
* ✅ Search accounts by customer name
* ✅ Input validation and custom exceptions
* ✅ Transaction history tracking

---

## 🧠 Tech Stack

* **Language:** Java
* **Concepts:** OOP, Streams, Exception Handling
* **Architecture:** Layered (app → service → repository → domain)
* **Tools:** VS Code, Git, GitHub

## ▶️ How to Run

### 1️⃣ Clone the repository

```bash
git clone https://github.com/kartikeyyy03/Banking-System-JAVA.git
cd Banking-System-JAVA
```

### 2️⃣ Compile

```bash
javac -d bin src/**/*.java
```

### 3️⃣ Run

```bash
java -cp bin app.Main
```
